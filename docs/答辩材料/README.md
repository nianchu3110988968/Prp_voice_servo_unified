## 对图讲解（约30秒）

用户唤醒机器人并说话后，ESP32采集录音，通过Wi-Fi发送给电脑。电脑先把语音转成文字，再由大模型结合人格设定生成回复，并选择动作。回复文字经过GPT-SoVITS合成为角色声音，机器人下载后播放。动作联动设计是在语音起播时触发舵机，从而把语言回应与肢体表达联系起来。简单来说，机器人负责听、说、动，电脑负责识别和生成。

## 图示范围与证据

依据2026-10-08最新进度及voice_motion_selection、servo_channel_setup指南绘制，展示普通对话核心流程，未展开预制词库、异常回退和连续对话循环。Wi-Fi箭头概括请求上传、回复元数据和音频下载，不表示电脑主动推送音频。

动作由对话模型选择，GPT-SoVITS仅合成语音。动作需经过允许列表、机器控制开关和忙碌等条件检查；语音起播联动软件已实现并通过离线验证，当前新版尚未完成上板及整机同步验收，因此图中使用虚线并明确标注。不得把此图作为五路运动、稳定行走或零时差同步已实测的证明。
