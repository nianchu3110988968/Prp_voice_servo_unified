## 1. 已确认的方向和接线

左右按机器人自身视角。用户确认原俯视照片左侧为前、右侧为尾部；实际接线以本表为准，不再采用旧0～4连续分配。

| 部位 | 串口名称 | PCA9685通道 |
| --- | --- | --- |
| 左前 | fl | 15 |
| 右前 | fr | 11 |
| 左后 | rl | 7 |
| 右后 | rr | 3 |
| 尾部 | tail | 0 |

通道不必连续，分散插接不影响50Hz控制。通道号不是ESP32 GPIO；I2C仍是GPIO1=SDA、GPIO2=SCL，音频引脚不动。

唯一接线配置入口：`main/robot_config.h` 的 `SERVO_CHANNELS`。固定五个部位，初始化、串口名称、限位和动作都使用此映射；动作数组始终按fl/fr/rl/rr/tail排列，不按物理通道号排列。编译时拒绝重复通道及0～15之外的编号。未来更换通道只修改这五项，重新编译并经确认烧录，不用更改动作数组。

`SERVO_LIMITS`记录每只舵机的软件范围和home值，目前仍是未校准的台架初值，所有home=90。改通道不等于完成方向/机械零位校准。

## 2. 上电前的门槛

- 用户照片确认驱动板为PCA9685，背面注明V+最高6V；VCC接ESP32的3V3，舵机V+使用独立稳压5V，共地，USB调试时外部5V不并到ESP32的5V/VIN。
- 当前电源板正面PW008、背面Gold-A029，分别引出VADJ、12V、5.0V、3.3V；照片可辨5.0V区域接线，但不能据此确认另一端的极性、实际电压或额定电流。不能把多路输出电流相加，也不能把不同电压的输出并联。蓝色电池包的电压、保护和电源板输入范围仍需核实。
- 用户目前没有万用表：保持舵机外部电源断开，可先离线编译。实际运动前借用万用表或有可靠读数/限流的测试电源确认5V及极性；五路并发前还需确认单路5V持续/峰值能力及主供电线。不能拿红色电源灯或电容上的耐压值代替测量。
- 主供电不用细杜邦线/面包板承载五路总电流；舵机电流直接经PCA电源端回外部电源，不经ESP32或音频地线回流。软件FULL OFF不切断V+，不能防止电源反接、过压或舵机内部故障。
- 舵盘已装且不便拆卸。第一次使能会直接发送home对应脉冲，SG90不回传当前角度，程序无法保证第一次不跳动。先托住身体、确认舵盘和线束有足够活动空间；若不能保证运动路径无干涉，先卸载连接或调整结构，不强行试0/180度。
- 原语音功能先做基线检查，再逐级复接。此前断开整个舵机子系统后音频恢复，只定位到该子系统，未锁定具体电气原因。OE硬件接法本轮没有修改，不能依赖旧单舵机指南的“始终接地”作为急停保护。

## 4. 后续批准上板后的尾部步骤

只有完成上一节验证、另行批准烧录、串口确认新版版本号，并满足供电与机械门槛后才能执行。不要把以下命令批量粘贴；一条完成、观察声音与动作后再输入下一条。

1. 支撑机身，输入 `end machine control`，再输入 `test audio`，确认原扬声器仍正常。
2. 输入 `start servo debug tail`。仅通道0发送home=90°（约1500μs）；其余15个通道保持FULL OFF。第一次可能跳到中位，这不是自动校准。
3. 尾部中位无干涉后，逐条输入 `servo tail 92`、`servo tail 90`、`servo tail 88`、`servo tail 90`，每次观察并记录方向。有尖叫、卡住、发热、无声或异常复位立即停止，必要时切断舵机外部电源。
4. 输入 `end servo debug`，关闭全部PWM并取消排队/正在执行的旧动作；再次用 `test audio` 对比。失去PWM保持力可能使身体下落，所以保持托举。

单路模式只允许所选部位home±5°（当前85～95°），拒绝其他部位、`motion`组合动作和直接切到整机模式；语音/AI/触摸动作入口仍关闭。重复start也拒绝，必须先end，避免反复跳中位。`end machine control`同样可以结束单路模式。

若已确认某一路home±5°仍会撞结构，不得使用这些默认值。首先离线修正该路home/限位或卸载机械约束；软件不能推断未测的安装角度。

## 5. 后续校准与动作目标（尚未实现新动作）

用户确认整机约200g，需要真实前进，不只是摆腿；坐下时后脚向身体内侧收。暂按侧面运动平面内“后脚下端朝腹部/前方收”理解，不是左右向中线夹腿，需用单路方向验证确认。

优先尝试保留现有舵盘安装，通过逐路记录home、前后方向和可用行程作软件校准；若安装齿位使站/坐姿超出可用行程，软件不能凭空增加行程，仍需机械调整。不凭照片把原始90°当竖直。

第一阶段只有映射和单路调试，不执行旧happy/shy/curious来代替新步态。之后再配置站姿、后腿内收坐姿、起身、对角步态。四个单关节腿无法独立控制抬脚和前后摆动；对称往复可能原地滑动。200g是用户估计，不是扭矩/重心验收；实际位移需结合支撑、足端摩擦、摆幅和相位落地测量，不能承诺仅靠对角交替必然前进。
