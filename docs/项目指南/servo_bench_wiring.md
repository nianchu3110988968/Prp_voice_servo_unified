# PCA9685 单舵机台架接线与测试

## 1. 本轮测试范围

本轮只验证 `ESP32-S3 -> PCA9685 -> 一只 SG90` 能否正常动作。

- 只连接一只舵机，插在 PCA9685 通道 `0`。
- 暂不连接其余舵机、触摸模块、加热片和震动马达。
- 舵机先卸下舵盘，或确保舵盘周围完全无遮挡。
- ESP32 由电脑 USB 供电；舵机使用另一组稳定的 5V 电源。

## 2. PCA9685 的两套电源

PCA9685 板上的 `VCC` 和 `V+` 不是同一个用途：

- `VCC`：给 PCA9685 控制芯片供电，接 ESP32 的 `3V3`。
- `V+`：给舵机电源排供电，接外部稳压电源的 `+5V`。
- `GND`：ESP32、PCA9685、外部 5V 电源必须共地。

因此，“舵机独立供电”是指外部 5V 接 PCA9685 的 `V+` 舵机电源端，而不是让舵机从 ESP32 开发板取电。本轮单舵机测试建议外部 5V 电源至少能稳定提供 2A；五个 SG90 的正式电源先按持续 5V/5A 级别验证。

## 3. 固定接线表

### 3.1 ESP32-S3 到 PCA9685 控制排针

| ESP32-S3 接口 | PCA9685 接口 | 作用 |
| --- | --- | --- |
| `3V3` | `VCC` | PCA9685 逻辑电源 |
| `GND` | `GND` | 逻辑地和公共参考地 |
| `GPIO1`（板上通常标 `1`） | `SDA` | I2C 数据 |
| `GPIO2`（板上通常标 `2`） | `SCL` | I2C 时钟 |
| `GND` | `OE`（仅当模块引出该脚） | 始终启用输出；无此接口则忽略 |

当前统一工程和旧舵机工程均固定使用 `GPIO1=SDA`、`GPIO2=SCL`，不要改接其他 GPIO。

### 3.2 外部 5V 电源到 PCA9685

| 外部 5V 电源 | PCA9685 接口 |
| --- | --- |
| `+5V` | 螺丝端子或舵机电源端的 `V+` |
| `GND/-` | 螺丝端子或舵机电源端的 `GND` |

再用一根线把外部电源 `GND/-` 与 ESP32 的任意 `GND` 相连。本轮不要把外部电源 `+5V` 接到 ESP32；ESP32 继续由 USB 供电。严禁把 `+5V` 接到 ESP32 的 `3V3`。

### 3.3 SG90 到 PCA9685 通道 0

以 PCA9685 板上印刷的 `GND / V+ / S` 标记为准：

| SG90 导线 | PCA9685 通道 0 |
| --- | --- |
| 棕色或黑色 | `GND`/`-` |
| 红色 | `V+`/`+` |
| 橙色、黄色或白色 | `S`/PWM |

若线色不同，必须先查舵机标签或规格页，不能试插。

## 4. 接线关系图

```text
电脑 USB
   │
   └── ESP32-S3
       ├── 3V3   ───────── PCA9685 VCC
       ├── GND   ───────── PCA9685 GND
       ├── GPIO1 ───────── PCA9685 SDA
       └── GPIO2 ───────── PCA9685 SCL

外部稳压 5V
   ├── +5V ─────────────── PCA9685 V+（舵机电源端）
   └── GND ─────────────── PCA9685 GND，并与 ESP32 GND 共地

PCA9685 通道 0
   ├── GND/- ───────────── SG90 棕/黑线
   ├── V+/+  ───────────── SG90 红线
   └── S     ───────────── SG90 橙/黄/白信号线
```

## 5. 上电前检查

1. 确认外部电源输出约为 5.0V；无法确认电压时不要连接舵机。
2. 确认 `VCC=ESP32 3V3`、`V+=外部5V`，两者没有接反。
3. 确认外部电源负极、PCA9685 GND 和 ESP32 GND 已共地。
4. 确认舵机插头没有反插。
5. 舵盘卸下或处于无负载状态。
6. 本轮只有 PCA9685 通道 0 接舵机。

## 6. 测试步骤

旧舵机工程当前使用 COM7，编译已经通过。确认接线安全后执行：

```powershell
cd E:\Projects2026\Prp
platformio run --target upload --upload-port COM7
platformio device monitor --port COM7 --baud 115200
```

程序启动时会给通道 0、1、2发送 90° 信号。因为本轮只接通道 0，所以只有一个舵机会动作。

在串口监视器中依次输入：

```text
r
s
c
r
```

预期表现：

- `r`：通道 0 回到约 90°；
- `s`：通道 0 缓慢转到约 45°，随后回到 90°；
- `c`：通道 0 缓慢转到约 130°，随后回到 90°；
- 全程不应持续抖动、异常发热、ESP32 重启或明显掉压。

若方向相反不代表故障，后续可调整动作映射。若舵机卡住、尖叫或明显发热，应立即断开外部 5V 舵机电源。

## 7. 通过标准

- PCA9685 初始化成功。
- 通道 0 能响应 `s`、`c`、`r`。
- 连续执行 5 次无卡死或失控。
- ESP32 串口不中断、不重启。
- 舵机和电源线无明显发热。
