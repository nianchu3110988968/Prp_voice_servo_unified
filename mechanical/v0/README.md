# PRP 五舵机骨架 V0 — 试装与评审版

**当前不是承重验收完成的打印定版。** 已依据商品图片创建真实B-Rep实体与分件STL；SKU、部分高度和舵盘孔位仍待实物核对。几何检查的实际结果见 `output/validation.json`，硬件证据见 `硬件尺寸与孔位核对.md`。

## 设计范围

- PLA；每个单独打印件小于200×200×200。整体装配不需要在打印机里一次成型。
- 主框架150×94×65；上层降压板最高参考到90。包含脚、扬声器和尾臂后的包络为220.7×166×104，明显大于初始70×50×50。
- 保留5只SG90、1块ESP32-S3、1块PCA9685、1块电池、2块降压板、功放和喇叭安装位置；麦克风和电源附件为明确标注的预留空间。没有假称未知充电/触摸模块均已完成专用安装。
- 底层可拆电池托，第二层主控/舵机驱动，顶层两路降压与小附件。电池供电后仍要给ESP32的5V/VIN提供合适电源；不能靠USB代替成品供电路径。两块降压器的输出不能直接并联。
- 四腿采用独立M4金属轴、金属轴套和连杆。承重路径为脚→腿→轴套/轴→双侧支座→主框架；SG90用原装舵盘驱动连杆。独立腿轴减少舵机径向载荷，**不减少需要的驱动扭矩**。
- 每腿只有一个摆动自由度，适合先验证站立和小幅姿态；不承诺实现任意方向行走或稳定步态。

## 文件与使用方法

| 文件/目录 | 用途 |
|---|---|
| `generate_frame.py` | 可重建的几何源程序；尺寸定义在构造调用中，修改后重新执行检查 |
| `requirements.txt` | CAD生成依赖；不属于ESP32固件依赖 |
| `output/cad_parameters.json` | 本版尺寸摘要，不是驱动所有几何的外部参数配置文件 |
| `output/PRP_V0_with_hardware.step` | 全装配评审，含标记REF的硬件简化包络；不能整体打印 |
| `output/PRP_V0_frame_only.step` | 打印结构的装配位置评审；也不是一体打印文件 |
| `output/step_parts/` | 每个打印件的独立STEP；坐标保留装配位置 |
| `output/stl_parts/` | 每个打印件已平移到打印平面；V0完整件，仅在试装通过后使用 |
| `output/stl_trial/` | 优先打印的小样：舵机安装板、孔径、轴套、夹具、原装舵盘适配件 |
| `output/validation.json` | 实体有效性、STL闭合性、尺寸、干涉和实心质量估计 |
| `output/assembly_preview.png` | 由真实几何渲染的预览，绿色等半透明块是硬件参考包络 |

用已安装CadQuery的Python执行 `python generate_frame.py`。本轮隔离生成依赖位于用户缓存，不改项目固件环境、不启动网络服务。STEP可由SolidWorks直接打开；导入实体不会自动拥有SolidWorks原生草图/拉伸特征树，修改复杂尺寸建议改几何源程序后重新导入。不得将原始STL统一缩放来修孔，否则所有安装尺寸一起改变。

## 关节与标准件

| 项目 | 首版建议 / 数量 | 注意 |
|---|---|---|
| 主关节轴 | M4×35半牙螺栓、垫圈、防松螺母，各4套 | 轴套接触范围应全部为光杆，核对实际螺栓光杆长度；不是3D打印轴 |
| 轴套 | 金属管外径6、内径4、长10，共4 | 轴套固定，腿在外径上转动；腿厚9.5、打印孔6.25，径向和端面间隙用小样验证 |
| 轴向隔套 | 内侧3.5、外侧2.5厚，各4组 | 用合适金属薄垫/隔套组合。固定内宽16=3.5+10+2.5；锁紧螺母不应夹住旋转腿端面 |
| 连杆销 | M2小螺栓、薄垫、防松螺母，8组 | 连杆2厚，与舵盘转接件/腿之间留活动间隙，不能锁死转动副 |
| 舵机固定 | M2螺栓/螺母，10组 | SG90原孔2.2；打印板2.4孔，不能硬塞M3 |
| 支座固定 | M3螺栓/螺母，16组 | 每个独立腿座4个，通孔3.3；螺栓长度按实际叠厚选取 |
| 板层及滑座固定 | M3螺栓/螺母/垫片，按装配 | V0均按通孔和背面螺母，不把3.3孔当自攻底孔；顶部长螺栓/拉杆须核对长度和工具空间 |
| 舵盘连接 | 使用SG90原装舵盘和原中心螺丝 | 不打印花键。适配件中的长槽只是试装结构，孔位/高度未经实物确认 |
| 电池固定 | 10宽魔术贴绑带2条、薄软垫 | 不用尖螺丝直接顶电池，不挤压电芯或引线根部 |
| 小PCB与线束 | 绝缘垫、合适夹具、细扎带 | 不能挡麦克风声孔或压焊点。试装夹具T03按实际板厚修订后再批量打印 |
| 脚底 | 软橡胶防滑垫4片 | PLA脚底本身不保证摩擦系数 |

以上是新增机械标准件需求，不是已购买库存。通孔、螺母及维修工具的可达性仍需实装确认；装配时先在主框架未封顶前穿好侧壁螺母。

## PLA打印起始参数

- 假设0.4喷嘴、0.20层高。承重框架与腿座建议5～6道壁、上下各至少5层、35～45%填充；薄连杆和舵盘适配件建议实心。
- 电子托板可用4道壁、25～35%填充。实际薄板/薄筋由外壁占主导，提高填充率不能弥补错误打印方向或尖角裂纹。
- STL已经放到Z=0。主框架底面朝下；腿和连杆平放，主弯曲受力方向在层面内。腿座按文件朝向放置，并在桥接/悬挑下使用可去除支撑，避开轴孔和贴合面。
- 腿座是试装版的厚实设计。实际质量以切片软件为准，CAD实心密度估算不是实际打印重量。
- 顶层降压器周围不得塞紧棉花；PLA的温升/蠕变必须在全装配环境验证。不要把商品标称8A当作毛绒封闭环境的持续输出能力。
- 先打印T01/T02/T04/T05并记录孔径、装配阻力和间隙；通过后先做单腿，再决定整套打印。T03用于小板夹持试验。

## 承重与扭矩边界

设整机质量M kg，最不利时两腿均分载荷，腿长52 mm，偏离竖直15°，两端曲柄均10 mm（近似1:1），动态系数2、传动效率暂取0.7：

`每只舵机所需扭矩 ≈ (M/2) × (5.2×sin15°) × 2 / 0.7 = 1.92M kgf·cm`

M=0.5 kg时约0.96 kgf·cm，M=0.7 kg时约1.35 kgf·cm。这是理想分载下的设计估算，未包含所有偏载、毛绒阻力和冲击；商品堵转扭矩也不能作为连续可用扭矩。实际重心可能让一条腿承担大于一半重量。静止竖直腿理论力臂接近零，不代表运动时仍无需扭矩。

本版没有设置已经验证的“最大承重”。如实物扭矩/电流/温升不过关，应更换舵机或增加机械减速/减载，并修改安装座，不能通过提高PLA填充率解决舵机扭矩不足。

## 验证与定版门槛

1. 台账中的SKU、孔位、板高、线束和舵盘尺寸完成实物核对。
2. 无电单腿试装：轴旋转顺畅、无明显晃动，连杆不卡，手动小幅摆动不碰加强筋。原装舵盘适配未通过前不带电加载。
3. 先以沙袋/砝码逐级加载一个关节，记录载荷、挠度、保持时间和卸载残余变形；再做四腿静态站立。不得直接拿已装电池的整机做跌落试验。
4. 低速小角度逐步上电，记录电压、舵机峰值/持续电流、温升和噪声。固件当前保守限位不自动等于新机构限位，需重新校准主页和方向；本轮不烧录。
5. 包含毛绒、线束、接头和填充物的最终状态再测热、卡滞和语音干扰。数值检查不包含柔性毛绒。

静态零干涉、离散姿态无碰撞和闭合STL只能证明对应模型的几何性质；不是有限元分析、连续运动证明、承重等级或实物验收。

## 本轮验证记录

- 32个分件均为有效单实体，STL闭合且面朝向一致；5种试装小样STL闭合。
- 静态打印件、硬件参考包络两两检查均无体积大于0.05mm³的干涉；四腿在±7.5°、±15°离散姿态无打印件干涉。这不是连续扫掠验证。
- 全装配STEP独立回读：56个实体、有效、包络220.7×166×104。
- SolidWorks 2024已实际打开并保存 output/PRP_V0_with_hardware.SLDASM，保留同目录STEP引用。属于STEP导入装配，不是原生草图特征历史，也尚未建立运动配合。
- CAD实心PLA估算368.26g；填充后的重量需切片计算，电子件/金属件/毛绒未计入。
- platformio run成功（RAM14.8%、Flash72.2%）；只作为项目要求的构建检查，不代表已烧录或承重/机械实测。本轮未修改固件与服务端逻辑。
