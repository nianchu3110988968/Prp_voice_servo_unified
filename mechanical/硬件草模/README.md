## SolidWorks 使用

1. 文件 → 打开，选择所需 STEP；导入后可另存为 SLDPRT。文件是导入实体，没有原生草图或特征历史。
2. 每个模型的 XY 外形中心为原点，最低面 Z=0；板卡元件侧朝 +Z，舵机输出轴朝 +Z。
3. 装配时重复插入 SG90 即可放置五路舵机；同型号降压板可按实际数量重复插入。
4. 00_硬件草模总览_非装配布局.step 将八种草模排成展示网格，方便同时查看，不代表机器人安装位置。

USB、排针、接插件和线材没有精确建模，实物布局需另留插拔和弯线空间。本批文件为外购硬件参考模型，不是待打印的骨架零件。

## 核验

八个单件均通过有效单实体、提取前后体积一致及 STEP 导出回读检查，结果见 提取核验.json。提取仅改变坐标与朝向，并将板卡相接的包络体合并；没有重新设计硬件外形。尚未进行本批单件的 SolidWorks 逐件导入或实物尺寸验收。
